# UI/UX Pro Max

When designing interfaces, strictly avoid "default AI" aesthetic patterns by incorporating the following:

## 1. Bespoke Aesthetics
- Avoid generic 3-column "features" grids and centered hero text without strong visual anchors.
- Utilize asymmetrical layouts, overlapping elements, or masonry grids when appropriate for a modern look.
- Use sophisticated typography pairings (e.g., a striking serif display font paired with a clean sans-serif for body text).

## 2. Dynamic Layout Variations
- Introduce varied section breaks instead of just alternating background colors (e.g., angled cuts, overlapping cards, soft gradient transitions).
- Use layered elevations (shadows and glassmorphism) deliberately, not arbitrarily.

## 3. Premium Interactive Patterns
- Add subtle parallax effects on scroll.
- Use staggered entrance animations for lists and grid items to build a sense of momentum.
- Provide delightful, unexpected micro-interactions (like buttons that morph on click or magnetic cursors) when they fit the brand.
