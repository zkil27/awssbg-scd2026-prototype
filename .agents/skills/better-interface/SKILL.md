# Better Interface

When applying UI layout changes, adhere to the following structural principles:

## 1. Spatial Grouping & Proximity
- Group related information visually (using containers, borders, or background colors).
- Ensure margins and paddings clearly establish relationships. Elements close together are perceived as related.

## 2. Reading Order & Hierarchy
- Maintain a logical visual hierarchy (F-pattern or Z-pattern reading order).
- Use clear visual anchors (headings, key buttons, icons) to guide the eye down the page.

## 3. Progressive Disclosure
- Avoid overwhelming the user with information. Hide advanced or secondary features behind "More options" links, accordions, or separate pages.
- Focus the default view on the primary user intent.

## 4. Responsive Breakpoints
- Establish clear layout shifts at standard breakpoints (e.g., `480px`, `768px`, `1024px`, `1280px`).
- Ensure navigation and complex grids gracefully degrade to single columns on small devices.
